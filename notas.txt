Paso a Paso
Como estaba en mi linux las instrucciones tienen comandos de linux

1. Instalar todo
sudo apt update
sudo apt install -y build-essential cmake pkg-config \
autoconf automake libtool git
sudo apt install -y libgrpc++-dev libprotobuf-dev protobuf-compiler-grpc protobuf-compiler

2. Compilar el proto
protoc -I=protos --grpc_out=protos --plugin=protoc-gen-grpc=`which grpc_cpp_plugin` protos/biblio.proto
protoc -I=protos --cpp_out=protos protos/biblio.proto

3. Compilar todo
mkdir -p build && cd build && cmake .. && make
